Trust, but verify

Check the seal.

Every file has a published SHA-256 checksum. Compare it with the value next to your download, or check them all at once against SHA256SUMS.txt.

Inside the app, updates go further: each one is checked against a signature before it is applied, and discarded if it doesn't match.

# Prints the SHA-256 of the file you downloaded
> Get-FileHash .\alchemist-setup.exe -Algorithm SHA256
# Prints the SHA-256 of the file you downloaded
$ shasum -a 256 alchemist.dmg
# Checks every file you downloaded against the published list
$ sha256sum -c SHA256SUMS.txt --ignore-missing

System requirements

Windows
Windows 10 or 11, x64 or arm64. Installer installs per-user, no admin needed.
macOS
macOS 12 Monterey or later. Separate builds for Apple silicon and Intel.
Linux
x64 or arm64. AppImage and tar.gz run anywhere; .deb and .rpm for Debian/Ubuntu and Fedora/RHEL families.
Hardware
Any recent machine. A GPU with video encoding makes recording and exporting faster, but isn't required.
